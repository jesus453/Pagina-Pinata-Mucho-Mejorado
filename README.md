# Pagina-Pinata-mejorado
Versión mejorada de pagina web de pinatas 

En este proyecto se planea mejorar el diseño de la página de piñatas anterior utilizando HTML y CSS, además se incluyen herramientas como React, Javascript 

En este proyecto se practica el diseño de páginas web y el manejo de HTML y CSS básico así como también adquirir conocimientos en javascript y React y dar como resultado una página web de piñatas más interactiva y atractiva.
